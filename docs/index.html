One request. Three steps.

Write what you need, follow creation and review, then inspect the files. This is a guide to the workflow, not a live AI execution.

  1. Write the request

    Describe the output and its acceptance criteria. Attach the source material the work needs.

  2. Follow the work

    Inspect drafting, review and revisions. Incomplete checks and failures stay visible; do not assume every request finishes.

  3. Review the files

    Compare revisions, inspect the checks, and download the work bundle when it is useful.

How to use it

Check what you need before you start.

Where it runs

Run it in your own environment. Choose a local connection such as Ollama, or connect Claude Code or an OpenAI-compatible endpoint.

What costs money

The software is MIT licensed. The contract and usage fees for the AI connection are separate.

Where data goes

With a local connection, input stays in your environment. A cloud model sends input to the provider you select.

Change direction

Attach txt, md or csv materials to a request. Directions sent while a run is active are recorded as events and handed to the next task session. Compare revisions, adopt the one you choose, and download the work bundle.

Install command

Prepare Ollama, Claude Code or another connection using the README. Copying this command does not mean that installation is complete.

uvx --from "git+https://github.com/FORIFOR/Multibot#subdirectory=backend" agentteam quickstart
