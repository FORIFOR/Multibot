# Agent Team SNS投稿草案

## 投稿案1: 開発者に革新をもたらすAIチームツール
AIチーム（Master/Researcher/Builder/Reviewer）が一度の依頼で連携し、成果物とBot間の実メッセージを実行記録とともに表示できる『Agent Team』。ローカルファーストで安心、オープンソースだから自由にカスタマイズ可能。ソフトウェア開発者と個人開発者に最適な新しい開発体験を提供します。

---

## 投稿案2: 効率的な開発を支えるAgent Team
『Agent Team』は、AIチームによる実作業と詳細な実行記録が一体となったツールです。Master、Researcher、Builder、Reviewerが連携し、品質の高い成果物を効率的に生み出します。オープンソース、ローカルファーストで、柔軟かつ安全にご利用いただけます。

---

## 投稿案3: Agent Teamで実現する次世代ソフトウェア開発
Agent Teamは、一度の依頼でAIチームが協働作業し、成果物・メッセージ・時系列を可視化します。個人開発者も安心して使えるローカルファースト設計で、オープンソースだからコミュニティと共に成長可能。新しい開発スタイルを体験してください。
