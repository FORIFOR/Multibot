## 本試験

`backend/scripts/local_benchmark_campaign.py` が、50課題×3回×2方式を1件ずつ実行します。方式の先行順を交互にし、各方式の実行ストアを分離します。予備試験は本試験の300件に算入しません。

コードは固定したcheckout、モデルdigest・設定ファイル・課題ソース・Ollama版はfingerprintに保存。途中でモデルや設定が変わると停止します。二重起動はロックで拒否し、既存の結果があるペアは再実行せず、失敗も保持します。接続不能や子プロセス異常はcampaign-status.jsonに記録して停止します。

実行開始時点では結果未確定です。終了後は全試行数、完了/失敗、自動採点、独立レビュー実施数、時間、トークン数を公開し、150件未完了の段階を「比較完了」とは呼びません。
