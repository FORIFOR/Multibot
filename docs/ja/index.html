04 / 始め方

あなたの環境で、
最初のお願いを。

アプリは無料のオープンソース。利用には対応するAIへの接続が必要です。

README ↗

ターミナルで実行

uvx --from "git+https://github.com/FORIFOR/Multibot#subdirectory=backend" agentteam quickstart

必要なものmacOS / Linux / Windows と uv。uv が未導入なら curl -LsSf https://astral.sh/uv/install.sh | sh（Windows は 公式の手順）。Python の準備は要りません。

  1. 起動する上のコマンドを実行すると、ブラウザで画面が開きます。
  2. AIにつなぐClaude Code、API、Ollamaから選んで、疎通を確認します。
  3. お願いするやってほしいことを、いつもの言葉で書きます。

利用料はかかりません。クラウドのAIを使う場合は、そのAIの利用料が別にかかります。

資料の行き先を、選べる。

Ollamaならローカルのモデルへ。クラウドのモデルを選ぶと、その接続先に入力が送られます。記録と成果物は実行環境に保存します。

FAQ

よくある質問

ChatGPTやClaudeと、何が違いますか？+

一人のAIが答えて終わりではなく、作る係と確かめる係が分かれています。受け取るのは返事ではなくファイルで、何を確かめたか、何が未確認かの記録も残ります。

必ず正しいものができますか？+

いいえ。確かめる係が見逃すこともあります。だから、未完了や未確認をそのまま表示し、うまくいかなかった実行記録も公開しています。大事な成果物は、ご自身でも確認してください。

料金はかかりますか？+

アプリは無料のオープンソース（MIT）です。クラウドのAIにつなぐ場合は、そのAIの利用料がかかります。一回ごとの予算上限を設定でき、達すると止まります。

登録してすぐ使えますか？+

まだ一般公開サービスは提供していません。現在は自分の環境への導入・試用ができます。公開環境、自己登録、運用体制、業務品質の受入を進めています。

データはどこに保存されますか？+

実行環境に保存されます。自分のPCに導入すればそのPC、専用サーバーならそのサーバーです。クラウドのAIを選ぶ場合は、入力がその接続先へ送られます。
