02 / 進める

追加で伝えたいことも、その場で。

作業中の画面から追加指示を送れます。誰が作業しているか、何ができたかも、同じ画面で確認できます。

追加指示の例：
「使い方は日本語で書いてください」

指示は次のタスクへ反映。進行中の処理をその場で書き換える機能ではありません。

このページでアプリを実行できますか？

上のガイドは、使い方を確認するためのものです。AIは実行しません。実際に依頼するには、お使いのPCでアプリを起動し、対応するAIへ接続してください。

利用料金はかかりますか？

ソフトウェアはMITライセンスのオープンソースです。AIサービスの契約料・利用料は別途、接続先の条件に従います。初回の接続確認でも小さな実呼び出しが行われます。

資料はどこへ送られますか？

実行記録や成果物は実行環境に保存されます。クラウドモデルを使う場合、処理に必要な入力は選んだ接続先へ送信されます。ローカルモデルでも、参照URLの取得などには外部通信を伴います。データと安全性について

成果物、修正履歴、成功・部分完了・失敗を含む評価を公開しています。実行例と制約、比較試験の記録をご確認ください。チーム構成による一般的な品質優位は、まだ示せていません。
