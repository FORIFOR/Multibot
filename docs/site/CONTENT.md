# Agent Team 公開文言の正本

実際の文言は [`copy.json`](copy.json) の日英各キー。`build_site.py` が共通構造へ読み込む。ここには文面の別コピーを置かず、変更時の条件を記す。

- 製品名は Agent Team、リポジトリは FORIFOR/Multibot。独断で改名しない。
- 資料を渡す→作成と確認→成果物と変更を読む→使う版を選ぶ、を説明する。
- 現在の提供はセルフホストでの試用。一般公開サービスは準備中。AI接続の準備と費用条件を隠さない。
- 保存先は実行環境、クラウドモデルを選ぶと入力はそのプロバイダーへ送られる。「PCの中だけ」という無条件の約束をしない。
- 代表例は `scenarios/research2` に保存された実記録。指摘3件への修正があっても、最終レビューは予算上限、原文逐一照合は未確認、実行全体はpartialを維持する。
- 変更前後は保存原文から抽出する。英語ページでも引用が日本語原文であることを明記する。英訳を原文のバイト列のように示さない。
- 旧合成ベンチマークを実企業の品質や現在のローカルモデルの成功率として使わない。
- キャラクターは役割図。静的ページでAIが動いているような成功演出はしない。
- 版の採用、モデルレビュー通過、機械検査、人間の受入は別の状態。
- 問い合わせは既存の非公開フォーム。送信成功だけを受付とする。検証のために架空の個人情報を送信しない。
- 賞は目標であり実績ではない。受賞ロゴ、第三者の推奨、架空の顧客や評価を置かない。
