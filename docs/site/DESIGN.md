# DESIGN.md — Agent Team サイト

## 型
- 最大幅 1200px。本文 18px / 行間 1.7。H1 は PC 56px、モバイル 36px。セクション間 96px（モバイル 64px）。ボタン高さ 48px（プロジェクト基準。WCAG 2.5.8 の最小は 24px）。
- 本文フォントは 1 種（IBM Plex Sans JP。英語ページも同系の IBM Plex Sans）。見出しは Fraunces。等幅は IBM Plex Mono（ハッシュ・時刻・コマンドのみ）。
- 色: 紙 `#f4efe6` / 墨 `#1b1a17` / 罫 `#cfc5b2` の中立色に、アクセントは酸化鉄 `#c8471f` の 1 色。合格は `#2f6b3a`、未検証は `#9a6a00`。装飾の勾配・光る球・ぼかしは使わない。

## ヒーロー
- 構成: コピー + 2 本の導線（主 CTA「実際の作業記録を見る」、副「GitHub で見る」）→ その直下に**作業記録**。
- 作業記録は 2/3 が成果物、1/3 が進行記録（依頼 → 初稿 → レビューの指摘 → 修正箇所 → 再検証）。
- 固有の操作: 進行記録の**指摘（F-1 / F-2 / F-3）をクリックすると、成果物の該当箇所へ移動し、変更前 (r1) / 変更後 (r2) を並べて示す**。
- 固有のモーション（サイトで 1 つ）: 「指摘から修正へ」。指摘クリック時に該当箇所へスクロールし、酸化鉄の枠が 1 回だけ脈動する。`prefers-reduced-motion` ではスクロールを即時、脈動を停止。

## ヒーロー 3 案（同じコピー・同じ素材）
- A: 成果物 2/3（左）+ 進行記録 1/3（右）。
- B: 進行記録 1/3（左）+ 成果物 2/3（右）。
- C: 進行記録を横一列（上）+ 成果物を全幅（下）。
- 比較は `variants/hero.html?layout=a|b|c`。スクリーンショットは `variants/hero-a.png` 他。**採用: A**。理由: 目線が成果物 → 指摘 → 該当箇所の順に左から右へ流れ、右列の指摘をクリックしたときに左の該当箇所が視野内に残る。B は指摘が先に目に入り「会話の画面」に見える。C は指摘と該当箇所が縦に離れ、クリック後の移動先が画面外に出る。モバイルは 3 案とも 1 列（成果物 → 記録）に畳む。

## 映像
- トップの映像は**実モデル実行の記録の再生**（`media/replay-research.mp4`、28.8 秒、無音）。ラベル: 「実行記録の再生」「23 分 51 秒の実行を 29 秒に短縮（待ち時間を短縮）」。ポスター画像あり、クリックで再生、自動再生しない。
- スクリプト provider のデモ（LLM 呼出なし）は別ブロック「再現できるデモ」に置き、実行記録と混ぜない。
- 映像 1 本につき目的 1 つ。ズームは読む箇所のみ。音声はナレーション版のみで、ユーザー操作で開始。
