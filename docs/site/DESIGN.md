# Agent Team 公開サイトのデザイン

現行: 2026-10-02、紙の作業台。詳細な評価軸と反復条件は [AWARD_QUALITY.md](../design/AWARD_QUALITY.md)。以前の青い背景・丸いカード・自動reveal・ヒーロー動画の構成を現行として扱わない。

## ブランドと情報順

アプリの Paper 方針を継承する。紙 `#fbf9f5`、墨 `#1b1a17`、赤い操作 `#bd411c`。既定の4つの形キャラクターは `frontend/src/assets/bots` の実SVGを生成時に読み込む。架空の稼働状態、チャット、顧客、評価、成功率を足さない。

- 最初に製品の動詞、資料からファイルへの仕事、試用範囲を説明する。公開アプリのログイン導線が未提供のため、存在しない登録ボタンを置かない。
- 主導線は「実際の修正を見る」。実記録の指摘→修正前→修正後→未確認の順に読む。主役となる対話は、保存された文面の選択表示。
- 次に現在の実アプリの依頼画面と、資料→確認→版の採用と保存の順序を見せる。採用は品質保証と表現しない。
- チーム紹介は罫線で役割を分ける。紹介カードの反復、常時ループ、スクロールの乗っ取りは使わない。
- 導入・データ送信先・FAQ・業務利用の相談へ続ける。問い合わせ先とデータ取扱いは既存の実サービスの説明を維持する。

## 実装の正本

- 文言: `docs/site/copy.json`（日英）。説明の仕様: [CONTENT.md](CONTENT.md)。
- 生成: `python3 docs/site/build_site.py` → `docs/index.html` / `docs/ja/index.html`。生成済みHTMLを直接編集しない。
- 書体: OSの日本語/欧文サンセリフとmono。外部フォントへの通信なし。
- スタイル: `docs/home.css` の単一表面。旧スタイルを末尾で上書きする積み重ねは廃止。
- 振る舞い: `docs/home.js`。本文をロード時に隠さない。JSがなくても3件の変更を文書順で読める。選択時の短い変化はreduced motionで止める。
- 原文: `docs/evidence/scenarios/research2/research.md.r1` / `research-final-r2.md.r1` から対象セル/行を直接抽出。SHAと全文リンクを併記。記録は書き換えない。

## 確認

`frontend/scripts/site-quality-audit.mjs` は実HTTP・実Chrome・axeによる再実行可能な確認。モック応答、模擬AI、合成売上などの入力は使わない。幅、JSなし、拡大、キーボード、動きを減らす設定、ローカル性能の測定条件を保存する。サイトの問い合わせは検査で送信しない。

スクリーンショットだけで賞や本番品質に合格したと扱わない。独立AI批評、機械検査、人間の判断を分ける。実Safari/iPhone、スクリーンリーダー、公開配信の実利用者指標は未確認。
