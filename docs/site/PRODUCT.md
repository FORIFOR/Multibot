# Agent Team 公開説明の製品事実

製品名: Agent Team。リポジトリ: FORIFOR/Multibot。MIT。日英ページ。

複数のAI担当が作成と確認を分担し、成果物の版と確認の記録を残す。Master、Researcher、Builder、Reviewerを、実アプリと共通の形キャラクターで表す。派手な表現を実行証拠や品質保証の代わりにしない。

## 現在の利用範囲

自分のPC/管理する環境へ導入して試せる。AI接続の設定が必要。一般公開のホスティング、自己登録、実際の運用・費用責任、第三者の自力利用、業務品質の受入は未完了。SSO・認可・永続キュー・バックアップ等の実装と、本番提供済みという判断は分ける。[公開サービス計画](../PUBLIC_SERVICE.md)と[本番計画](../PRODUCTION_PLAN.md)を参照する。

## 公開する実記録

`docs/evidence/scenarios/research2/` の3つの公開ページを比較する調査メモ。記録上は2026-09-13 JST、Claude Code接続（provider reported opus-5）による履歴。F-1根拠引用欠落、F-2関係性未確認、F-3原文にない言い換えへの修正を追える。最終レビューの予算上限でpartial、原文逐一照合はunverified。これを現在のローカルモデルや一般業務の品質証明にはしない。

生成スクリプトは保存された初稿と修正版の該当行/セルを抽出する。原文ファイルとSHAを公開ページから辿れる。表示を良くする目的で失敗、留保、原文を成功に書き換えない。
