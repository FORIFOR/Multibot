# 参照画像の記録

他社の画面の画像は、権利上このリポジトリ（公開）には置かない。手元の `artifacts/ui/references/`（Git管理外）に置き、ここには記録だけを残す。

## voiceos.com — ホームページ
- 対象: homepage。取得日 2026-09-19。
- 確認方法: 本文の取得（HTML→文章）と Lighthouse 12（モバイル既定、各1回）。**画面の画像は開いていない = VISUAL UNVERIFIED。**
- 採用したい属性: 1セクション1主張、短い文、最初の画面に製品の姿、登録なしの主CTA、プライバシーの独立した節、FAQ。
- 模倣しない属性: 根拠の示されていない「10倍」、推薦文と利用者数（こちらには実在しない）、写真的な背景素材。
- 測定値の比較は `docs/site/ACCEPTANCE.md`。

## wonder.next-standards.com — 初回案内
- 対象: app のオンボーディング2画面（01/05 紹介、02/05 サインイン）。取得日 2026-09-19。1440×900、DPR 1、headless Chrome。
- 確認方法: スクリーンショットを撮り、画像として開いて確認した（確認者: Claude）。ワークスペース本体はサインインが必要で**未確認**。
- 採用したい属性: 利用者とAIチームの間に立つ1体の相棒、左右分割の落ち着いた案内、空のグラデーションと明朝体の見出し、半透明の面、進み具合の点。
- 模倣しない属性: マスコットの意匠（他社のもの）。こちらは製品の4人を磨く。
- 差: 相手のマスコットは描き起こされた立体のイラスト。こちらはCSSで組んだ図形で、作り込みは及ばない。
