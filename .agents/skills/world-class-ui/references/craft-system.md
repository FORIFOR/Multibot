# Craft system — 実装に落とすための指針

これは独自の設計指針。特定社のCSS・数値の再現ではない。既存の承認済み設計を優先する。

## 構図と情報
一画面の主役と読む順番を定める。主役は巨大文字とは限らず、成果物、実画面、利用者の仕事でもよい。
余白は情報のまとまりを示すために使い、面積を増やすだけで高品質と扱わない。
囲いが情報関係を示さないなら外す。同じ角丸カードを並べる前に文書・リスト・比較・時間順を検討する。
視覚順とDOM/読み上げ順を一致させる。ページ装飾のためにスクロールを奪わない。

## Typography
英語の短い仮見出しではなく、本番相当の日本語で先に組む。
書体はブランド、可読性、字種、利用条件、読み込み負荷で選ぶ。奇抜な書体を選ぶこと自体を目標にしない。
見出し・本文・ラベル・補足の役割を階層化し、不必要なサイズと太さを増やさない。
長文、英数字、絵文字、長いURL、翻訳による伸長、欠損値で崩れないようにする。
固定のbrや文字数切りで見出しを無理に整えない。意味のある改行と可変幅を両立する。
小さい薄灰色文字で情報を隠さない。数値を比較する画面では桁・単位・整列も揃える。

## Tokens
primitive値と、用途を示すsemantic tokenを分ける。数値は既存stackで管理する。
spacingは少数の段階から始め、光学補正が必要なら理由を残す。全画面に同じ幅・密度を強制しない。
radius、shadow、borderも階層と用途に合わせる。全部を同じカードにせず、無制限にも増やさない。
accentは選択、主操作、特徴的な一箇所に使い、警告などの意味色と混同しない。
light/darkの対応範囲は先に決める。自動反転だけで読みやすさを確認したことにしない。

## Components and behavior
利用する各componentにdefault / hover / focus-visible / pressed / disabled / loading / errorの必要な状態を持たせる。
意味のあるnative control・既存のアクセシブルなprimitiveを優先する。
ボタンは操作、リンクは遷移。無効な理由と解除方法を必要箇所で説明する。
入力のhintはlabelの代用にしない。IME変換確定のEnterと送信のEnterを区別する。
dialogの開始/終了フォーカス、Escape、背景への操作、エラー位置を確認する。
通知を唯一の成功確認にせず、保存済みの内容や現在状態を画面から確かめられるようにする。

## Responsive and mobile
小画面では優先順位から組み直す。desktopの3列を同じ順で縦積みすれば完了とはしない。
固定ヘッダー・下部バー・safe area・ソフトキーボード・スクロール領域の重なりを確認する。
必要な操作はタッチでも発見可能にし、hoverや細いアイコンだけに依存しない。
Webの開始候補は幅360/390/768/1440 CSS px。必要に応じ320、端末固有の幅、200%拡大も追加する。
これらは提案する試験点であって、VoiceOS/PLAUDの実測値でも全端末保証でもない。
モバイルviewportやWebKitエミュレーションを、実iPhone Safariの検証と呼ばない。

## Motion
役割を先に書く: 状態変化、空間のつながり、原因と結果、必要な注意。
操作を遅らせない。割込み、連打、取消、途中の状態変化でも破綻しないようにする。
常時ループ、全カードの浮遊、全セクションの同じ出現演出を既定にしない。
reduced motionで理解に必要な内容が欠落しない代替を作る。
静止画では動きの良さを検証できない。操作・録画・性能計測を分けて行う。

## Assets and demos
実コンテンツまたは明示したfixtureを用い、架空の顧客・実績・評価を作らない。
製品UIを紹介するデモは、入力→変化→成果物が分かる一つの仕事を使う。
録画/再現アニメーション/実操作デモを区別し、押せない映像を操作可能に見せない。
取得済みで利用可能な画像を使う。外部画像のhotlinkは許可・安定性・プライバシーを確認する。
本物のUI文字を画像生成に任せず、実DOMまたはアプリの実画面から作る。
欠損画像、縦横比違い、長いタイトルに対応し、特定素材にしか合わない画面を作らない。
フォントの実ファイルを成果物として勝手に再配布しない。

## 手戻りを減らす順序
主タスクと構図→実コンテンツ→余白/文字→部品/状態→動き/素材→実機での仕上げ。
既存の表示を壊す大規模リファクタリングと見た目の調整を、理由なく一緒に行わない。
デザインの正本から実装箇所まで追えるようにし、放置された仮tokenや重複CSSを残さない。
